# The base apache/airflow:2.9.3-python3.11 image already has the heavy
# dependencies the DAGs need (SQLAlchemy, pandas, psycopg, etc.).
#
# One addition: the DAG imports src/alert_manager and uses astk.db, so the
# scheduler/worker image must be able to import `astk`. astk's core pulls in
# pydantic-settings and typer on top of what the image already has.
#
# astk is a PRIVATE repo. The image installs it via a BuildKit secret named
# ASTK_PAT (a GitHub token) — see airflow/Dockerfile and docker-compose.yml.
# Non-Docker installs need git credentials for the private repo on PATH, or
# astk already importable (e.g. on PYTHONPATH).
